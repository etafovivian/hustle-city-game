# Holy books (Phone → Holy books)

Public-domain texts from Project Gutenberg, split into chapters by `apps/web/scripts/holy-books.py`
(Gutenberg's header and licence text removed, as allowed for public-domain works; no wording changed).

- **The Holy Bible, King James Version**: Project Gutenberg ebook #10.
- **The Qur'an in English**: Abdullah Yusuf Ali and Marmaduke Pickthall, from "Three translations of the Koran (Al-Qur'an)
  side by side", Project Gutenberg ebook #16955. Public domain in the USA.
- **The Bhagavad Gita, "The Song Celestial"**: translated by Sir Edwin Arnold (1885), Project Gutenberg ebook #2388.
